# Portfolio · Andrea Soteldo

Sitio estático publicado en Cloudflare Pages: https://andrea-soteldo.pages.dev

- `index.html`: versión en español
- `en/index.html`: versión en inglés
- `style.css` y `site.js`: compartidos por las dos versiones
- `img/`: capturas de las tiendas y de los proyectos

No hay build: Cloudflare publica la raíz del repo tal cual. Cada push a `main` despliega solo.

Para verlo en local:

```bash
python3 -m http.server 8000
```
